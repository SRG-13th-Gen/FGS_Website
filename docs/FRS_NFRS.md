## Boundaries

The admin is the sole editor; imported stories remain editable without native WordPress links. Inquiry submission, enrollment processing, payments, student records, visitor accounts, search and analytics are outside the delivered scope. Contact details are displayed, but no delivery service is implied.

Do not advance unresolved accessibility, privacy, audit or performance proposals merely because code exists. [DECISIONS](DECISIONS.md) records approval; [contracts](DATA_API_CONTRACTS.md) describe implemented behavior.

# Public Assets

This directory contains static assets served by Next.js. Place images, fonts, and other media here.

## Structure

- `images/logo/` — School logo files (PNG, SVG)
- `images/gallery/` — Gallery section photos
- `images/hero/` — Hero section background images
- `images/general/` — Other general-purpose images (campus, events, etc.)

Files here are served from the root URL. For example:
- `public/images/logo/fgs-logo.png` → accessible at `/images/logo/fgs-logo.png`
